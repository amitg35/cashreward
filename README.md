# CashReward Privacy Policy

This repository contains the public Privacy Policy page for **CashReward**.

## Files

- `privacy-policy.html` — Public Privacy Policy webpage.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `cashreward-privacy`.
2. Upload `privacy-policy.html` and this `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Click **Save**.
6. Wait for GitHub Pages to publish the site.

Your Privacy Policy URL will normally be:

`https://YOUR-USERNAME.github.io/cashreward-privacy/privacy-policy.html`

You can also rename `privacy-policy.html` to `index.html`. Then the URL becomes:

`https://YOUR-USERNAME.github.io/cashreward-privacy/`

## Telegram Bot

Use the public GitHub Pages URL in **BotFather → Privacy Policy**.

## Before publishing

Review the Privacy Policy and replace any placeholder support/contact information with your official CashReward contact details. Make sure the policy accurately describes the data your actual app and third-party services collect and process.
